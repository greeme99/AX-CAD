# 이 코드를 실제 프로젝트 폴더 구조로 배치한 완성형 템플릿 만들고, pytest 와 FastAPI TestClient 통합 테스트 코드 작성하고, React UI 를 shadcn/ui 기반으로 고도화 하고, 도커 및 쿠버네티스 배포 구성안 작성한다. 중요한 것은 반드시 근거가 있는 소스를 찾아서 신뢰할수 있고 바로 코딩에 사용할 수 있도록 개발 가이드 만든다

아래는 **실제 프로젝트에 바로 넣을 수 있는 수준의 템플릿 패키지**로 정리한 가이드입니다. FastAPI의 `TestClient`로 통합 테스트를 돌리고, shadcn/ui의 “코드를 직접 소유하는” 구성 철학에 맞춰 React UI를 구성하며, PostgreSQL은 `CREATE VIEW`, `CREATE TRIGGER`, 트리거 함수 규약에 맞춰 운영형 DDL로 묶었습니다.[^1][^2][^3][^4]

## 2. FastAPI + TestClient 통합 테스트

FastAPI 공식 문서에서 `TestClient`는 별도 HTTP 소켓 없이 앱 내부와 직접 통신하는 방식으로 테스트할 수 있다고 설명합니다.[^7][^1]

### `backend/tests/integration/test_quote_api.py`

```python
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)

def test_import_dxf_success():
    payload = {
        "quote_request_id": 1,
        "document_no": "DWG-001",
        "title": "Test Drawing",
        "file_name": "sample.dxf",
        "file_content_base64": "ZHVtbXk="
    }
    response = client.post("/api/quote/import/dxf", json=payload)
    assert response.status_code == 200
    body = response.json()
    assert body["success"] is True
    assert "entity_count" in body["data"]

def test_import_step_success():
    payload = {
        "quote_request_id": 1,
        "document_no": "PRT-001",
        "title": "Test Part",
        "file_name": "sample.step",
        "file_content_base64": "ZHVtbXk="
    }
    response = client.post("/api/quote/import/step", json=payload)
    assert response.status_code == 200
    assert response.json()["success"] is True

def test_generate_quote_success():
    payload = {
        "quote_request_id": 1,
        "rule_set_version": "1.0",
        "price_master_version": "1.0"
    }
    response = client.post("/api/quote/generate", json=payload)
    assert response.status_code == 200
    body = response.json()
    assert body["success"] is True
    assert body["data"]["quote_no"].startswith("Q-")

def test_quote_trace_endpoint():
    response = client.get("/api/quote/Q-2026-0001/trace")
    assert response.status_code == 200
    assert response.json()["success"] is True
```

### `frontend/src/components/quote/QuoteBuilder.tsx`

```tsx
"use client";

import { useMemo, useState } from "react";
import { Button } from "@/components/ui/button";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { Input } from "@/components/ui/input";
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";
import { Textarea } from "@/components/ui/textarea";
import { Badge } from "@/components/ui/badge";

type QuoteLine = {
  line_no: number;
  item_code: string;
  item_name: string;
  qty: number;
  unit: string;
  unit_price: number;
  amount: number;
};

export function QuoteBuilder() {
  const [quoteNo, setQuoteNo] = useState("Q-2026-0001");
  const [customerName, setCustomerName] = useState("A사");
  const [notes, setNotes] = useState("");
  const [lines, setLines] = useState<QuoteLine[]>([
    { line_no: 1, item_code: "DXF_LINE_CUT", item_name: "레이저 절단", qty: 12.5, unit: "m", unit_price: 1500, amount: 18750 }
  ]);

  const total = useMemo(() => lines.reduce((sum, l) => sum + l.amount, 0), [lines]);

  return (
    <div className="grid gap-4 lg:grid-cols-[280px_1fr_320px]">
      <Card>
        <CardHeader><CardTitle>Source Files</CardTitle></CardHeader>
        <CardContent className="space-y-3">
          <Input type="file" />
          <Button className="w-full">DXF 업로드</Button>
          <Button className="w-full" variant="secondary">STEP 업로드</Button>
        </CardContent>
      </Card>

      <Card>
        <CardHeader><CardTitle>견적 라인</CardTitle></CardHeader>
        <CardContent className="space-y-3">
          <div className="grid gap-2 md:grid-cols-2">
            <Input value={quoteNo} onChange={(e) => setQuoteNo(e.target.value)} />
            <Input value={customerName} onChange={(e) => setCustomerName(e.target.value)} />
          </div>

          <Table>
            <TableHeader>
              <TableRow>
                <TableHead>No</TableHead>
                <TableHead>Code</TableHead>
                <TableHead>Name</TableHead>
                <TableHead className="text-right">Qty</TableHead>
                <TableHead>Unit</TableHead>
                <TableHead className="text-right">Unit Price</TableHead>
                <TableHead className="text-right">Amount</TableHead>
              </TableRow>
            </TableHeader>
            <TableBody>
              {lines.map((l) => (
                <TableRow key={l.line_no}>
                  <TableCell>{l.line_no}</TableCell>
                  <TableCell><Badge variant="outline">{l.item_code}</Badge></TableCell>
                  <TableCell>{l.item_name}</TableCell>
                  <TableCell className="text-right">{l.qty}</TableCell>
                  <TableCell>{l.unit}</TableCell>
                  <TableCell className="text-right">{l.unit_price.toLocaleString()}</TableCell>
                  <TableCell className="text-right">{l.amount.toLocaleString()}</TableCell>
                </TableRow>
              ))}
            </TableBody>
          </Table>
        </CardContent>
      </Card>

      <Card>
        <CardHeader><CardTitle>Summary</CardTitle></CardHeader>
        <CardContent className="space-y-3">
          <div className="text-2xl font-semibold">{total.toLocaleString()} KRW</div>
          <Textarea value={notes} onChange={(e) => setNotes(e.target.value)} placeholder="검토 메모" />
          <Button className="w-full">견적 생성</Button>
          <Button className="w-full" variant="secondary">검증</Button>
          <Button className="w-full" variant="outline">PDF Export</Button>
        </CardContent>
      </Card>
    </div>
  );
}
```

## 4. Docker 구성

Docker는 애플리케이션과 의존성을 컨테이너 이미지로 묶는 표준 방식으로, 공식 문서의 Dockerfile 지침을 따르는 것이 안전합니다.

### `backend/Dockerfile`

```dockerfile
FROM python:3.11-slim

WORKDIR /app

ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1

RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

COPY backend/pyproject.toml ./pyproject.toml
COPY backend/app ./app
COPY backend/tests ./tests

RUN pip install --no-cache-dir fastapi uvicorn[standard] pydantic sqlalchemy psycopg2-binary ezdxf pytest httpx

EXPOSE 8000
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```


### `frontend/Dockerfile`

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY frontend/package*.json ./
RUN npm install

COPY frontend ./
RUN npm run build

EXPOSE 3000
CMD ["npm", "run", "start"]
```

Kubernetes는 컨테이너화된 앱의 배포, 확장, 관리를 위한 오케스트레이션 엔진입니다. 따라서 backend, frontend, postgres를 분리 배포하고, config/secret/ingress/hpa를 붙이는 구성이 기본입니다.[^9]

### `infra/k8s/backend-deployment.yaml`

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cad-backend
spec:
  replicas: 2
  selector:
    matchLabels:
      app: cad-backend
  template:
    metadata:
      labels:
        app: cad-backend
    spec:
      containers:
        - name: backend
          image: registry.local/cad-backend:latest
          ports:
            - containerPort: 8000
          envFrom:
            - configMapRef:
                name: cad-config
            - secretRef:
                name: cad-secret
```

## 7. 최소 체크리스트

- FastAPI 테스트는 `from fastapi.testclient import TestClient`로 구현.[^1][^7]
- shadcn/ui는 공식 사이트 기준으로 component code를 프로젝트에 직접 넣는 방식.[^6][^2]
- PostgreSQL trigger는 function을 먼저 만든 뒤 `CREATE TRIGGER`로 연결.[^3][^10][^4]
- DXF는 `modelspace`, `blocks`, `layouts` 중심으로 파싱.[^11][^12][^13]
- STEP는 part/assembly/PMI를 구분해 견적 규칙에 반영.[^14][^15]
