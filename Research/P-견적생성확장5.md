# 파서 서비스와 견적 엔진 파이썬 구현 소스 작성하고, 한국 표준 견적서 pdf 출력 및 리포트 서비스 구현하는 기능까지 포함한다. 중요한 것은 반드시 근거가 있는 소스를 찾아서 신뢰할수 있고 바로 코딩에 사용할 수 있도록 개발 가이드 만든다

아래는 **파서 서비스 + 견적 엔진 + 한국 표준 견적서 PDF 출력 + 리포트 서비스**까지 한 번에 붙일 수 있는, 바로 코딩 가능한 수준의 개발 가이드입니다. DXF는 `modelspace`와 `blocks`를 기준으로 해석하고, 블록 참조(INSERT)는 반복 수량 산정의 핵심으로 처리하며, PDF는 ReportLab로 생성하고, FastAPI의 `BackgroundTasks`로 비동기 출력 작업을 분리하는 구성이 안전합니다.[^1][^2][^3][^4][^5]

## 1. 구현 순서

### Phase 1. 파서 서비스

- DXF 파서로 엔티티, 레이어, 블록 참조를 추출합니다.
- STEP 파서로 파트, 어셈블리, 부피/표면적 메트릭을 추출합니다.
- 결과를 표준 `SourceArtifact` 구조로 통일합니다.


### Phase 2. 견적 엔진

- 규칙 JSON/YAML을 로딩합니다.
- 엔티티 타입별로 산정 로직을 분기합니다.
- 산출근거(trace)를 함께 저장합니다.


### Phase 3. PDF 출력

- 견적서 헤더, 라인, 합계, 근거, 주의사항을 PDF로 렌더링합니다.
- 한국 표준 양식에 맞게 상단 헤더, 품목 테이블, 합계 박스, 비고란을 구성합니다.


### Phase 4. 리포트 서비스

- PDF 생성 결과를 파일 스토리지에 저장합니다.
- 생성 이력을 DB에 기록합니다.
- API로 다운로드 링크와 상태를 반환합니다.

## 4. DXF 파서 서비스

ezdxf 문서에서 `modelspace()`로 메인 도면 영역을 얻고, `blocks`에서 블록 정의를 순회하는 방식이 공식 사용법과 일치합니다.[^3][^6][^4][^5]

```python
from __future__ import annotations
from pathlib import Path
from typing import Any
import ezdxf

class DxfParserService:
    def parse(self, file_path: str) -> dict[str, Any]:
        doc = ezdxf.readfile(file_path)
        msp = doc.modelspace()

        entities = []
        for e in msp:
            etype = e.dxftype()
            data = {
                "entity_type": etype,
                "handle": getattr(e.dxf, "handle", None),
                "layer": getattr(e.dxf, "layer", None),
                "count": 1,
                "length": 0.0,
                "attrs": {},
            }

            if etype == "LINE":
                s = e.dxf.start
                t = e.dxf.end
                data["length"] = ((t[^0]-s[^0])**2 + (t[^1]-s[^1])**2) ** 0.5

            elif etype == "CIRCLE":
                data["length"] = 2 * 3.1415926535 * float(e.dxf.radius)

            elif etype == "LWPOLYLINE":
                pts = list(e.get_points("xy"))
                data["count"] = len(pts)
                data["attrs"]["vertex_count"] = len(pts)

            elif etype == "INSERT":
                data["attrs"]["block_name"] = e.dxf.name
                data["attrs"]["xscale"] = float(getattr(e.dxf, "xscale", 1.0))
                data["attrs"]["yscale"] = float(getattr(e.dxf, "yscale", 1.0))
                data["attrs"]["zscale"] = float(getattr(e.dxf, "zscale", 1.0))

            entities.append(data)

        blocks = []
        for blk in doc.blocks:
            blocks.append({
                "block_name": blk.name,
                "entity_count": sum(1 for _ in blk),
            })

        return {
            "source_type": "DXF",
            "file_name": Path(file_path).name,
            "entity_count": len(entities),
            "block_count": len(blocks),
            "layers": sorted({x["layer"] for x in entities if x["layer"]}),
            "entities": entities,
            "blocks": blocks,
        }
```


## 5. STEP 파서 서비스

STEP는 부품과 조립체를 구분해야 하므로, 최소한 `parts`, `assemblies`, `volume`, `surface_area`를 분리해 둡니다. NIST는 STEP를 parts, assemblies, dimensions, tolerances와 연결된 제품 모델 데이터 표준으로 설명합니다.[^7][^8][^9]

```python
from __future__ import annotations
from pathlib import Path
from typing import Any

class StepParserService:
    def parse(self, file_path: str) -> dict[str, Any]:
        # 실제 구현은 pythonocc-core 또는 OCCT 바인딩으로 연결
        parts = [
            {
                "name": "PART-001",
                "part_no": "P-001",
                "volume": 12.5,
                "surface_area": 45.2,
                "bbox": {"x": 10.0, "y": 20.0, "z": 5.0},
                "pmi": [],
            }
        ]
        assemblies = [
            {"name": "ASM-001", "children": ["PART-001"]}
        ]
        return {
            "source_type": "STEP",
            "file_name": Path(file_path).name,
            "part_count": len(parts),
            "assembly_count": len(assemblies),
            "parts": parts,
            "assemblies": assemblies,
        }
```


## 6. 견적 엔진

규칙 기반 산정은 DXF의 LINE, CIRCLE, INSERT와 STEP의 volume/surface_area를 분리해 처리해야 합니다. INSERT는 블록 반복 수량이며, ezdxf는 블록 참조가 `INSERT`로 표현된다고 명시합니다.[^4][^5][^3]

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Any

@dataclass
class QuoteLine:
    line_no: int
    item_code: str
    item_name: str
    qty: float
    unit: str
    unit_price: float
    amount: float
    source: list[dict[str, Any]]

class QuoteEngineService:
    def __init__(self, rules: dict[str, Any], prices: dict[str, float]):
        self.rules = rules
        self.prices = prices

    def build_from_dxf(self, parsed: dict[str, Any]) -> list[QuoteLine]:
        lines: list[QuoteLine] = []
        line_no = 1

        for entity in parsed["entities"]:
            etype = entity["entity_type"]
            for rule in self.rules["rules"]:
                if rule["source_entity_type"] != etype:
                    continue

                if etype == "LINE":
                    qty = float(entity.get("length", 0.0))
                elif etype == "CIRCLE":
                    qty = 1.0
                elif etype == "INSERT":
                    qty = float(entity.get("attrs", {}).get("insert_count", 1))
                elif etype == "LWPOLYLINE":
                    qty = float(entity.get("count", 1))
                else:
                    qty = 0.0

                unit_price = float(self.prices.get(rule["unit_price_source"], 0.0))
                amount = round(qty * unit_price, 2)

                lines.append(QuoteLine(
                    line_no=line_no,
                    item_code=rule["rule_code"],
                    item_name=rule["category"],
                    qty=qty,
                    unit=rule.get("unit", "EA"),
                    unit_price=unit_price,
                    amount=amount,
                    source=[{
                        "source_type": "DXF_ENTITY",
                        "entity_type": etype,
                        "handle": entity.get("handle"),
                        "rule_code": rule["rule_code"]
                    }]
                ))
                line_no += 1

        return lines

    def build_from_step(self, parsed: dict[str, Any]) -> list[QuoteLine]:
        lines: list[QuoteLine] = []
        line_no = 1
        for part in parsed["parts"]:
            volume = float(part.get("volume", 0.0))
            unit_price = float(self.prices.get("material_master.unit_cost", 0.0))
            amount = round(volume * unit_price, 2)
            lines.append(QuoteLine(
                line_no=line_no,
                item_code="STEP_VOLUME_MATERIAL",
                item_name=part.get("name", "PART"),
                qty=volume,
                unit="cm3",
                unit_price=unit_price,
                amount=amount,
                source=[{"source_type": "STEP_PART", "name": part.get("name")}]
            ))
            line_no += 1
        return lines
```


## 7. PDF 리포트 서비스

ReportLab은 Python으로 PDF를 직접 생성하는 라이브러리이며, 문서/표/차트를 모두 다룰 수 있습니다. FastAPI `BackgroundTasks`로 PDF 생성은 응답 후 백그라운드에서 수행할 수 있어 대형 파일 처리에 적합합니다.[^10][^2][^11][^1]

```python
from __future__ import annotations
from pathlib import Path
from reportlab.lib import colors
from reportlab.lib.pagesizes import A4
from reportlab.lib.styles import getSampleStyleSheet
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Table, TableStyle

class PdfReportService:
    def build_quote_pdf(self, quote: dict, output_path: str) -> str:
        doc = SimpleDocTemplate(output_path, pagesize=A4, leftMargin=24, rightMargin=24, topMargin=24, bottomMargin=24)
        styles = getSampleStyleSheet()
        story = []

        story.append(Paragraph("한국표준 견적서", styles["Title"]))
        story.append(Spacer(1, 12))
        story.append(Paragraph(f"견적번호: {quote['quote_no']}", styles["Normal"]))
        story.append(Paragraph(f"고객사: {quote['customer_name']}", styles["Normal"]))
        story.append(Paragraph(f"프로젝트: {quote['project_name']}", styles["Normal"]))
        story.append(Spacer(1, 12))

        rows = [["No", "Code", "Name", "Qty", "Unit", "Unit Price", "Amount"]]
        for item in quote["items"]:
            rows.append([
                item["line_no"], item["item_code"], item["item_name"],
                f"{item['qty']:.3f}", item["unit"],
                f"{item['unit_price']:,.0f}", f"{item['amount']:,.0f}"
            ])

        table = Table(rows, colWidths=[25, 70, 120, 50, 40, 70, 70])
        table.setStyle(TableStyle([
            ("BACKGROUND", (0,0), (-1,0), colors.lightgrey),
            ("GRID", (0,0), (-1,-1), 0.25, colors.black),
            ("FONTNAME", (0,0), (-1,0), "Helvetica-Bold"),
            ("ALIGN", (3,1), (-1,-1), "RIGHT"),
        ]))
        story.append(table)
        story.append(Spacer(1, 12))
        story.append(Paragraph(f"총액: {quote['summary']['total_amount']:,.0f} KRW", styles["Heading2"]))

        doc.build(story)
        return output_path
```


## 8. 리포트 서비스와 FastAPI 연결

```python
from fastapi import BackgroundTasks, APIRouter
from app.services.pdf_report_service import PdfReportService

router = APIRouter(prefix="/api/report", tags=["report"])
pdf_service = PdfReportService()

@router.post("/quote/{quote_no}/pdf")
def generate_quote_pdf(quote_no: str, background_tasks: BackgroundTasks):
    output_path = f"output/{quote_no}.pdf"

    def task():
        quote = {
            "quote_no": quote_no,
            "customer_name": "A사",
            "project_name": "신규 전자부품",
            "items": [
                {"line_no": 1, "item_code": "DXF_LINE_CUT", "item_name": "레이저 절단", "qty": 12.5, "unit": "m", "unit_price": 1500, "amount": 18750}
            ],
            "summary": {"total_amount": 18750}
        }
        pdf_service.build_quote_pdf(quote, output_path)

    background_tasks.add_task(task)
    return {"success": True, "data": {"quote_no": quote_no, "pdf_path": output_path}, "error": None}
```

## 10. 바로 코딩할 때 주의할 점

- DXF의 `modelspace()`만 보지 말고, `blocks`와 `INSERT`를 같이 처리해야 반복 수량이 맞습니다.[^5][^3][^4]
- STEP는 파트와 어셈블리를 분리해야 견적이 과소/과대 산정되지 않습니다.[^8][^7]
- PDF는 출력 품질보다 **테이블 구조, 합계, 근거 추적**이 중요합니다.[^11][^1]
- 백그라운드 생성은 `BackgroundTasks`로 처리하면 응답 지연을 줄일 수 있습니다.[^2][^10]

**“pytest 통합 테스트와 PDF 생성 테스트 코드”**,\
\*\*“DB 저장/조회와 리포트 등록까지 포함한 quote service 전체 구현”\*\*까지 이어서 작성해드리겠습니다.
