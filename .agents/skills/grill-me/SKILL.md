# GRILL-ME — Spec Clarification Protocol

Do NOT write code until ambiguities are resolved:
1. Clarify goals, scope, and non-goals.
2. Ask at most 3-5 sharp, high-leverage multiple-choice questions.
3. Freeze technical specifications, boundary conditions, and test verification gates.
4. Proceed to implementation only after spec confirmation.
