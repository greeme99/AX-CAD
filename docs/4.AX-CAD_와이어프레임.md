# AX-CAD 와이어프레임 V1.0

> 7단계 개발 절차 중 **4단계 산출물**. 정보구조도(SCR)별 레이아웃·구성요소·인터랙션을 정의한다.
> 기본 레이아웃은 `DESIGN.md` §3.1 **5분할 워크스페이스**(상단 헤더 / 좌 구조 / 중앙 캔버스 / 우 속성 / 하단 명령·상태)를 따른다.
> 원칙: 캔버스 최우선 · 좌측은 구조, 우측은 속성, 하단은 상태 · 명령은 항상 텍스트로도 표시 (`P-Design-System` §9)

## 1. 화면별 레이아웃

### [SCR-01] 로그인

- **화면 목적**: 인증 후 역할에 맞는 홈으로 이동.
- **레이아웃**: 중앙 카드(400px) — 로고, 입력, 버튼. 배경 `bg-base`.

| 요소 | 타입 | 동작 | 비고 |
|---|---|---|---|
| 아이디 | input text | 필수, 자동 포커스 | |
| 비밀번호 | input password | 필수, Enter 제출 | 표시 토글 |
| 로그인 | button primary | 제출, 로딩 스피너 | 중복 클릭 방지 |
| 오류 메시지 | inline alert | 실패 사유(잠금 시 남은 시간) | 계정 존재 여부 비노출 |

### [SCR-05] 도면 상세·개정 이력

- 좌: 메타데이터 카드(번호, 제목, 유형, 상태, 현재 Rev), 썸네일
- 중앙: 개정 이력 타임라인(Rev, 작성자, 일시, 메모, 엔티티 수)
- 우: 승인 이력, [두 개정 비교] 결과(추가/삭제/변경 수 요약)

### [SCR-11] 견적서 미리보기·출력

- 좌: 출력 옵션(형식, 근거 별첨 여부, 공급자 정보 선택)
- 중앙: PDF 미리보기(A4, 페이지 넘김)
- 우: 출력 이력(일시·형식·초안 여부·다운로드)
- 하단: [생성] [다운로드]

### [SCR-12/13] 승인함 / 승인 상세

- 승인함: 대기 목록 테이블(유형, 대상, 요청자, 요청일, 검증 상태) → 행 클릭
- 승인 상세: 좌 대상 요약, 중앙 미리보기(도면 뷰어 읽기 전용 또는 견적 테이블), 우 검증 결과·이전 개정 비교·코멘트, 하단 [반려] [승인]
- 반려 시 코멘트 필수.

### [SCR-14] BOM

- 상단: BOM 번호, 원천 Revision, [재생성] [CSV] [JSON] [ERP 전송(승인 후)]
- 중앙: 품목 테이블(No, 품번, 품명, 규격, 수량, 단위, 원천, 매핑 상태) — 미매핑 행은 경고 배지 + 품번 선택 콤보

### [SCR-16] 기준정보 관리

- 상단: 버전 선택(▾) + [새 버전 복제] + 적용일
- 좌: 카테고리(재질/공정/임률·경비/원가 비율/매핑 규칙)
- 중앙: 편집 가능한 테이블(인라인 편집, 행 추가), 저장 전 변경 diff 표시
- 확정된(적용 중) 버전은 읽기 전용

### [SCR-15/17/18] 관리자 기타

- 사용자: 테이블 + 역할 멀티선택 + 활성/잠금 해제
- 연동 모니터링: 작업 테이블(대상, 상태, 시도 수, 마지막 오류) + [재시도]
- 감사 로그: 필터(대상 유형/ID/사용자/기간) + old/new JSON diff 뷰

## 3. 반응형 설계 기준

CAD 편집은 정밀 마우스 조작이 필요하므로 데스크톱을 기준으로 한다(SRS NFR-06).

| 화면 폭 | 업무 화면 | 워크벤치(SCR-06/07/09) |
|---|---|---|
| ≥ 1440px | 풀 레이아웃, 사이드바 펼침 | 좌 260 / 우 320 패널 모두 펼침 |
| 1280 ~ 1439px | 사이드바 아이콘(64px) | 좌 패널 기본 접힘(오버레이로 열기) |
| 768 ~ 1279px (태블릿) | 단일 컬럼 테이블, 사이드바 드로어 | **조회 전용**: 뷰어·견적 열람, 편집 도구 숨김, 안내 배너 |
| ≤ 767px (모바일) | 목록·승인함·견적 요약만 | 미지원 안내(데스크톱에서 열기) |
