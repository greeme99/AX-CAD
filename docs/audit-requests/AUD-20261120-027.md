## Root Cause
- `AX-CAD_Start.bat` launched `uvicorn` (`:8000`) and `pnpm dev` (`:3000`) without verifying that PostgreSQL (`localhost:5432` / `axcad-dev-pg`) was running or that DB migrations were up to date.
- When Docker Desktop / `axcad-dev-pg` was stopped, backend `/api/health` returned `503 Database unavailable` (`psycopg.errors.ConnectionTimeout`) and DB-backed endpoints returned HTTP 500.

## Scope
- `AX-CAD_Start.bat`: Added Step `[1/5]` (detect `:5432`, auto-launch Docker Desktop if needed, `docker start axcad-dev-pg`, wait for port `:5432`) and Step `[2/5]` (`uv run alembic upgrade head`).
