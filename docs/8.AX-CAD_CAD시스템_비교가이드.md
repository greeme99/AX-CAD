# AX-CAD CAD 시스템 비교 가이드 V1.0

> **기준일: 2026-11-11** (자동화 표는 plan §22 W0~W10 반영, 그 밖의 표는 2026-11-09 `main` = PR #62 기준). AX-CAD의 **현재 구현 상태**를 상용·오픈소스 CAD(AutoCAD, Siemens NX, FreeCAD)와 견주어, "무엇을 대체하고 무엇은 일부러 하지 않는지"를 한눈에 보는 문서다.
> 최초 비교 가이드(AutoCAD·NX 대비 R2.0 보완 3건: 조립·간섭, 판금, 파라미터 블록·자동화)는 `plan.md` §15의 출발점이었고, 이 문서는 그 이후 구현(Track 9~11, 2D 자동화 §20, 언더레이 §21)까지 반영한 **현재 값**이다.

## 0. 읽는 법과 신뢰 수준

| 열 | 근거 | 신뢰 수준 |
|---|---|---|
| **AX-CAD 현재** | 이 저장소의 코드·테스트·문서(`docs/2` FN, `docs/7` TC, `plan.md`). 아래 "근거" 열의 ID로 추적 가능 | **확인됨** (자동 테스트·CI) |
| AutoCAD · NX · FreeCAD | 제품 공통의 **일반 지식**과 사용자가 제공한 가이드(PDF/DWF 언더레이·LISP/VBA/.NET)의 서술 | **참고용** — 버전·라이선스별로 다를 수 있어 도입 판단 전에 해당 버전 공식 문서로 확인 |

표기: ● 지원 · ◐ 부분(제한 있음) · ○ 지원하지 않음 · — 해당 없음

## 1. 한 줄 포지셔닝

| 시스템 | 성격 | AX-CAD와의 관계 |
|---|---|---|
| AutoCAD | 범용 2D/3D 도면 표준(DWG), 풍부한 자동화(AutoLISP·VBA·.NET) | **2D 도면·자동화 사용 경험을 따라가되**, 도면에서 견적·BOM까지 한 시스템으로 잇는 것이 목적 |
| Siemens NX | 통합 제품개발(CAD/CAM/CAE, PLM) | 파라메트릭·조립·판금 **개념만** 참고(범위는 부품 200개·기본 판금까지) |
| FreeCAD | 오픈소스 파라메트릭 3D | 알고리즘을 **클린룸으로 재구현**(코드 복사 없음, LGPL 고려) |
| **AX-CAD** | 중견 제조사용 **PC 설치형 사내 CAD + 한국표준 자동 견적** | 도면 형상 → 공정 규칙 → 단가 → 견적 라인 **추적성**이 차별점 |

> **"완전"의 뜻**(plan §22.2): AutoCAD와 100% 동일이 아니라, 공식 레퍼런스 목록 대비 위 비율 + 레퍼런스 예제 적합성 테스트 통과다. 분모에서 뺀 항목(plan §22.5, 스크립트가 이름을 부르면 명확한 오류)은 다음과 같다.
>
> | 언어 | 의도적으로 빼는 것 |
> |---|---|
> | LISP | `startapp`·`shell` 등 외부 프로그램, ARX/FAS/DLL 로딩, 레지스트리 직접 접근(설정 저장소로 대체), 데이터 폴더 밖 파일, 메뉴·툴바·도움말 창(`menucmd` 등), OS 프로세스 `acet-sys-*` |
> | VBA (ActiveX) | 3D 솔리드·서피스·메시 생성(`Add3DFace`·`AddBox` 등), 외부 참조·래스터(`AttachExternalReference`·`AddRaster`·`Bind`), COM·ARX·VBA 프로젝트(`GetInterfaceObject`·`RunMacro`·`Eval`), 데이터 폴더 밖 파일·URL(`Open`·`SaveAs`·`WBlock`), AutoCAD 창·메뉴·환경설정, 플롯(PLOT 대화상자 사용) — 143쌍 |
> | .NET | 앱 안 코드 실행(플러그인 DLL), 3D 솔리드·플롯 API. SDK는 REST로 같은 편집 API를 부름 |
>
> 알려진 동작 차이: VBA `Height`·`InsertionPoint` 등 블록 속성의 위치·크기는 블록 정의가 정하며 읽기만 안내, 기존 블록의 내용은 서버에 있어 이름 변경·삭제만(내용 재정의는 2D 화면), ActiveX Double 속성의 실수 표시는 대표 속성 기준.

> **의도적 차이**: AutoCAD는 앱 안에서 임의 네이티브/관리 코드를 실행하지만, AX-CAD는 신뢰할 수 없는 스크립트를 가정해 **해석기 + 한도 + 공통 객체 모델**만 허용한다(보안 검토 BUG-62). 그래서 `(command "undo")`·외부 프로그램 호출·파일 임의 접근은 막혀 있다.

## 4. 알려진 한계와 미검증 항목 (2026-11-09)

- AutoCAD가 만든 **실제 DWFx/DWF 파일**로는 검증하지 못했다(합성 샘플 기준). 사용자 PC 실사용 검증 항목은 `docs/HANDOFF.md` §4에 있다.
- 한 번 타임아웃이 나면 같은 시점의 다른 파싱 작업도 함께 실패한다(워커 풀 재시작). OS 수준 샌드박스는 배포 환경의 몫이다.
- 위 표의 AutoCAD·NX·FreeCAD 열은 일반 지식이므로 구매·도입 판단용 근거로 쓰기 전에 해당 버전 공식 문서를 확인한다.
- G1 기준정보(실제 단가·품셈 값)와 수기 견적 3건 비교(TC-67)는 사용자 입력 대기이므로, 견적 정확도 비교는 아직 **합성 데이터 기준**이다.
