# AX-CAD UI 디자인 시안 V1.0

> 7단계 개발 절차 중 **5단계 산출물**.
> **단일 진실 공급원(SoT)은 루트 `DESIGN.md`**다. 이 문서는 DESIGN.md의 토큰을 화면·컴포넌트 단위로 적용하는 방법을 정리하며, 값이 충돌하면 DESIGN.md를 따른다.
> 시각 시안 참고: 루트 `design_preview.html`. Research(`P-shadcn/ui 템플릿`)의 HSL 토큰은 사용하지 않는다(Research 결함 D10).

## 1. 디자인 컨셉

- **톤앤매너**: 신뢰감 있는 클린 라이트 SaaS(기본) + 다크/글래스 테마. 캔버스는 쉘 테마와 독립된 전용 테마.
- **핵심 원칙**
  1. 캔버스가 가장 넓고 가장 대비가 높다.
  2. 수치(좌표·치수·금액)는 모노스페이스, 우측 정렬.
  3. 상태는 색 + 아이콘 + 텍스트를 함께 사용한다(색맹 대응).
  4. 견적 라인 ↔ 도면 객체가 같은 하이라이트 색(`cad-selection`)으로 연결된다.

## 3. 컴포넌트 스타일 가이드

### 3.1 간격·모서리·그림자

| 항목 | 값 |
|---|---|
| 간격 스케일 | 4px 베이스: 4 / 8 / 12 / 16 / 24 / 32 |
| 패널 내부 패딩 | 12px, 패널 간 간격 12~16px |
| 모서리 | 버튼·입력 8px, 카드 12px, Pill(툴·토글·배지) 9999px |
| 그림자 | 카드 `--shadow-card`, 플로팅 팔레트·드로어는 한 단계 강하게 |
| 아이콘 | lucide-react, 툴 아이콘 20px(버튼 32px), UI 아이콘 16px |
| 높이 | 헤더 56px, 명령창 36px, 상태바 28px, 테이블 행 36px(고밀도 32px) |

### 3.2 버튼

| 종류 | Default | Hover | Active | Disabled |
|---|---|---|---|---|
| Primary | bg `primary-solid`, 흰 글자 | `primary-solid-hover`, `translateY(-1px)` | translateY(0) | 불투명도 .5, 커서 not-allowed, 툴팁에 사유 |
| Secondary | bg `surface`, 테두리 `border-strong` | bg `hover` | | 동일 |
| Ghost | 투명 | bg `hover` | | 동일 |
| Destructive | bg `danger` | 진하게 | | 동일 |
| Tool(Pill) | 투명, 아이콘 | bg `hover` | 선택: bg `primary-light` + 글자 `primary-hover`(대비 4.5:1) | |

- 포커스: 2px `primary` 링 + 2px 오프셋(키보드 접근성).

### 3.3 입력 필드

| 상태 | 스타일 |
|---|---|
| Default | bg `surface`, 테두리 `border`, 높이 36px |
| Focus | 테두리 `primary` + 포커스 링 |
| Error | 테두리 `danger`, 하단 오류 문구(12px, 아이콘 포함) |
| Disabled | bg `subtle`, 글자 `text-muted` |
| 수치 입력 | mono, 우측 정렬, 단위 접미(`mm`, `원`) |

### 3.4 카드·패널·테이블

- 카드: bg `surface`, 모서리 12px, `--shadow-card`, 패딩 16px
- 워크벤치 패널: bg `surface`, 경계선 `border`, 그림자 없음(캔버스와 평면 정렬)
- 테이블: 헤더 bg `subtle` + `title-md`, 행 hover `hover`, 선택 행 좌측 3px `cad-selection` 바, 숫자 열 mono·우측 정렬, 합계 행 굵게 + 상단 2px 경계

### 3.5 CAD 특화 컴포넌트

| 컴포넌트 | 스타일 |
|---|---|
| ToolPalette | 플로팅 Pill 그룹, bg `surface`(다크: 글래스 `backdrop-blur`), 활성 툴 `primary-light` |
| LayerRow | 높이 28px, [표시 체크][👁][🔒][색 스와치 12px][이름], 활성 레이어 굵게 |
| SnapToggle | 상태바 Pill 토글, 켜짐 = 스냅 종류별 마커 색 점 + 텍스트 |
| CommandPrompt | mono, bg `subtle`, 프롬프트 텍스트 `text-muted`, 오류는 `danger` |
| PropertyRow | 라벨 40% / 값 60%, 값은 인라인 편집 mono |
| QuoteRow 상태 배지 | §1.3 매핑 |

| ValidationItem | [아이콘][코드][메시지], 클릭 시 대상 포커스 |

### 3.6 모션

- 기본 150ms ease-out(hover, 토글), 드로어·다이얼로그 200ms
- `prefers-reduced-motion` 시 모든 이동 애니메이션 제거
- 캔버스 줌/팬은 애니메이션 없이 즉시 반영(정밀 작업)

## 6. 구현 매핑 (Tailwind v4 + shadcn/ui)

```css
/* frontend/src/app/globals.css — DESIGN.md 토큰을 그대로 선언하고 shadcn 변수에 연결 */
@import "tailwindcss";

:root, [data-theme="light"] { /* DESIGN.md §2.1 Light 값 */ }
[data-theme="dark"]        { /* DESIGN.md §2.1 Dark 값 */ }

@theme inline {
  --color-background: var(--color-bg-base);
  --color-card: var(--color-bg-surface);
  --color-muted: var(--color-bg-subtle);
  --color-foreground: var(--color-text-main);
  --color-muted-foreground: var(--color-text-muted);
  --color-ring: var(--color-primary);
  --color-snap: var(--color-cad-snap);
  --color-selection: var(--color-cad-selection);
  --color-warning: var(--color-cad-warning);
  --color-dimension: var(--color-cad-dimension);
  --font-sans: "Pretendard", -apple-system, BlinkMacSystemFont, "Inter", sans-serif;
  --font-mono: "JetBrains Mono", "Fira Code", monospace;
}
```

- 임의 색상(hex 직접 사용) 금지, 반드시 토큰 클래스 사용(`DESIGN.md` §0).
- 캔버스 렌더러(Canvas2D/Three.js)는 CSS 변수를 `getComputedStyle`로 읽어 사용한다.
