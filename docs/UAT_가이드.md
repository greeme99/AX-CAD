# AX-CAD UAT 실행 가이드 (PC 설치본 기준)

> 대상: UAT를 진행하는 설계·견적·생산·관리자 담당자와 운영 지원 개발자.
> 시나리오 목록과 결과 기록은 `docs/7` §7(U-01~U-13)이 원본이다. 이 문서는 **준비 → 실행 → 기록** 방법만 다룬다.
> **V1.2 (2026-11-02)**: Track 7(PC별 설치, 로그인·결재·ERP 실연동 제거) 이후 기준으로 다시 썼다. 이전 판(서버·계정·승인 시나리오)은 폐지되었다.

## 요약

| 단계 | 내용 | 담당 |
|---|---|---|
| 0. 환경 | 시험 PC에 **설치본**을 설치한다 (새 DB가 만들어져 개발 데이터가 섞이지 않는다) | 개발·IT |
| 1. 프로젝트 | UAT 프로젝트 만들기. 로그인·역할 계정은 없다 | 담당자 |
| 2. 기준정보 | G1 작성본 가져오기 → 내용 확인 → 확정(되돌릴 수 없음) | 견적 |
| 3. 실행 | U-01~U-13을 사내 실도면으로 수행 | 각 역할 |
| 4. 기록 | `docs/7` §7 결과 열 + 결함은 아래 양식 | 각 역할 → 개발 |

## 0. 환경 준비

### 0.1 설치

UAT는 사용자가 실제로 쓰게 될 **PC 설치본**으로 한다. 서버·Docker·계정 준비가 필요 없다.

1. 개발 측이 Actions **Windows release**로 만든 `AX-CAD-<버전>-win-x64.zip`과 `SHA256SUMS.txt`를 받는다. 해시는 다른 경로(사내 공지)로도 받아 비교한다.
2. 시험 PC(Windows 10/11, 메모리 8GB 이상 권장)에서 압축을 풀고 `install.cmd`를 실행한다(관리자 권한 불필요). 자세한 절차와 문제 해결은 [PC 설치·업데이트 가이드](PC_설치_가이드.md) §2.
3. 견적서에 실제 공급자 정보를 쓰려면 `%LOCALAPPDATA%\AX-CAD\data\supplier.json`을 메모장으로 열어 회사 정보로 바꾼다. 샘플 그대로면 견적서에 "샘플 공급자" 워터마크가 찍힌다(U-05에서 확인).
4. DWG 도면을 쓰려면 변환기(ODA File Converter)를 먼저 설치한다(PC 가이드 §3.1).

설치본의 데이터는 그 PC의 `data\`에만 있다. 개발 DB와 섞일 일이 없다. UAT가 끝나고 데이터를 버릴 때는 `data\backup`에 백업을 남길지 먼저 정한다(UAT 결과의 근거가 된다).

### 0.2 확인

| 확인 | 방법 |
|---|---|
| 설치·실행 | 시작 메뉴 **AX-CAD** → 브라우저에 AX-CAD가 열리고 로그인 화면 없이 홈이 보임 |
| 버전 | 왼쪽 메뉴 **업데이트**에 `R1.0`과 변경 내역이 보임 |
| 데이터 비혼입 | 프로젝트 목록이 비어 있음, 기준정보 버전 없음 |

## 1. 프로젝트 준비

로그인과 역할 계정이 없다. 이 PC의 사용자는 모든 메뉴를 쓴다. **프로젝트**(`/projects`)에서 UAT 프로젝트를 만든다. 담당자별 시나리오는 같은 PC를 돌아가며 쓰거나, 각자 자기 PC에 설치해 같은 도면 파일을 올려서 수행한다(PC 간 데이터 공유는 없음).

> 이전 판의 "승인 시나리오는 요청자와 승인자가 달라야 한다"는 조건은 승인 제도 폐지(Track 7)로 없어졌다.

## 2. 기준정보 준비 (견적)

1. 메뉴 **기준정보**(`/admin/master-data`) → 새 버전 생성.
2. G1 작성본 엑셀을 **G1 엑셀 가져오기**로 넣는다. 재질·단가·공정 규칙·원가 비율·레이어 규칙(시트 1~6)과, 공종 단가·보정계수·구매품 단가·표준품셈·도면 객체 시트가 이 초안으로 들어간다. 오류는 시트·행 단위로 표시된다.
3. 화면에서 값을 원본 엑셀과 대조한다.
4. **활성화(확정)**: 이후 수정 불가. 바꾸려면 복사해 새 버전을 만든다. 확정 전에 3번을 끝낸다.

기준정보가 없으면 견적이 기본 규칙으로 계산되어 금액 비교(U-05, TC-67)가 의미 없다. G1 작성본(단가·임률)과 실제 공급자 정보는 저장소에 올리지 않는다.

## 3. 시나리오 실행

공통 규칙:
- **사내 실도면**을 쓴다(합성 도면은 개발 테스트에서 이미 검증됨). 기밀 도면은 시험 PC 밖으로 내보내지 않는다.
- 각 시나리오는 "확인 기준"을 하나라도 못 맞추면 Fail로 기록하고 결함을 남긴다.
- 화면 캡처는 결함 재현에 필요한 범위만 남긴다(단가·고객명 노출 주의).

| # | 절차 (화면 경로) | 확인 기준 |
|---|---|---|
| U-01 | 프로젝트 → 도면 생성 → **DXF 업로드**(또는 빈 도면) → 개정 행에서 뷰어 열기 → 선·원 작도, 이동, 치수 추가 → 저장 | 레이어·치수 표시, 저장 시 새 리비전(A→B), 잠긴 레이어 객체는 수정 불가. 해치·블록·지시선이 있는 도면이면 표시 확인 |
| U-02 | 도면 화면 → 3D 모델(`/model/<도면>`) → 구속 스케치 → 돌출·포켓·회전 → 필렛·모따기·구멍, STEP 가져오기·내보내기 | 부피·면적 표시, 내보낸 STEP을 사내 CAD에서 다시 열 수 있음 |
| ~~U-03~~ | ~~도면 승인 요청 → 승인/반려~~ | **폐지** (Track 7) |
| U-04 | 뷰어 **견적 메트릭** → 견적 생성 → 견적 화면에서 라인 클릭(추적 드로어) → 단가·공수 수동 조정(사유) | 라인별 근거(원천 엔티티 → 규칙 → 단가), 원천 하이라이트, 조정값과 자동값이 따로 보임 |
| U-05 | 견적 화면 **견적서 출력**: PDF·Excel (내부용 산출근거 첨부 선택) | 수기 견적과 **원 단위** 일치(TC-67), 공급자 정보 실제 값(샘플 워터마크 없음). 승인 단계는 없음 |
| U-06 | 조립 도면 업로드 → 도면 화면 **BOM** → BOM 생성 → 미매핑 블록에 품번 지정 → CSV 내려받기 | 블록 수량 = 실제 수량, 미매핑 표시, CSV를 엑셀로 열었을 때 수식 실행 없음 |
| U-07 | BOM 화면 **ERP 업로드 파일(Excel)** 내려받기 → 회사 ERP의 일괄 등록 화면에 올림 | 미매핑이 0건일 때만 내려받아짐. 회사 ERP 양식과 열 이름·순서가 맞는지 확인(안 맞으면 알려 주면 `ERP_COLS`만 조정) |
| U-08 | **기준정보** 가져오기·확정, **감사 로그**(`/admin/audit`) 확인 | 변경 이력 기록. 사용자·역할 관리는 서버 모드 전용이라 대상 아님 |
| U-09 | 사내 부품 몇 개를 3D로 모델링(스케치·돌출·가공)해 부피·STEP을 기존 CAD와 비교 | 선택 모서리 재탐색 허용 범위(몸체 크기 10%)가 실제 수정 폭에 맞는지 확인 |
| U-10 | 3D 모델 화면 **도면 만들기** → 투상도·단면·치수·구멍 지시·표제란 → 사내 도면 양식과 비교. 사내 표제란이 있는 DXF 시트를 올려 **PDF 출력**(시트 그대로)도 확인 | 뷰 배치·선 굵기·치수 위치·구멍 지시 표기·표제란 항목 차이만 기록 |
| U-11 | 기준정보 **기본 가공 규칙 넣기** 후 사내 공수표·임률·기계경비로 값 교체 → 3D 부품(구멍·탭 포함) 견적 → 사내 견적서와 비교 | 소재 여유(원가 비율)·공수·임률·기계경비 반영, 규격품 구매 단가 |
| U-12 | 평면도 리비전 → 공사 견적(실·벽·문 수량산출, 철거/신설/유지) → 공종 단가 또는 품셈 → 공사원가계산서·내역서 | 손계산 내역서와 원 단위 일치, 품셈 라인에 고시·페이지 출처 표시. G1 `12_품셈항목` 등의 예시("?")를 실제 값으로 바꾼 뒤 수행 |
| U-13 | **AX-CAD 백업** → 다른 폴더에 복사 → 데이터 삭제 → 복구 → 화면 **업데이트**로 패치(R1.0 → 수정 1) 적용 | 데이터 유지, 실패해도 이전 버전으로 자동 원복. 절차는 PC 가이드 §4.4 (TC-158) |

## 4. 결과·결함 기록

### 4.1 결과

`docs/7` §7 표의 **결과** 열에 `Pass` / `Fail(UAT-xx)` / `보류(사유)`와 수행일·수행자 역할을 적는다.

### 4.2 결함 양식

| 항목 | 작성 예 |
|---|---|
| ID | UAT-01 (순번) |
| 시나리오 | U-04 |
| 심각도 | Critical(업무 불가·금액 오류) / Major(우회 가능한 기능 오류) / Minor(표시·문구) |
| 재현 절차 | 1) 도면 X 업로드 2) 견적 메트릭 3) … |
| 기대 결과 | 절단 길이 1,234.5mm |
| 실제 결과 | 1,200.0mm |
| 첨부 | 도면 파일명·리비전 ID, 화면 캡처(민감정보 가림) |
| 환경 | 설치 버전(R 표기, 업데이트 화면), 브라우저(Chrome/Edge 버전), 해상도 |

- **금액 차이**는 견적 화면의 추적 드로어(원천 → 규칙 → 단가)를 캡처해 함께 남긴다. 수기 견적서와 같은 줄끼리 비교한다.
- 오류가 나면 `%LOCALAPPDATA%\AX-CAD\data\logs`의 최근 로그 파일을 보낸다. **`data\axcad.env`(DB 비밀번호·설치 토큰)는 보내지 않는다.**
- 지원 브라우저는 Chrome·Edge 최신 2개 버전, 1280px 이상 데스크톱이다(NFR-06). 그 밖의 환경 문제는 Minor로 분류한다.

## 5. 종료 기준

`docs/7` §6 릴리스 판정 기준을 따른다: 해당 릴리스 UAT Pass 100%, Critical·Major 결함 0건. Minor 결함은 PO 승인 시 조건부 릴리스.
