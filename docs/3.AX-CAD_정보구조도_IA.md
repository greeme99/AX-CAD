# AX-CAD 정보구조도 (IA) V1.2

> **V1.2 (2026-11-09)**: SCR-21(언더레이 패널), 마이그레이션 0025~0028(조립·판금·견적 도면 구분·`underlay_files`), `needs_quote` 컬럼 반영.

> 7단계 개발 절차 중 **3단계 산출물**. 기능명세서(FN)를 메뉴·화면·데이터 구조로 배치한다.
> 근거: `P-Design-System`(네비게이션 구조, 워크벤치), `P-개발참조1·2`(화면 목록, DDL), `P-견적산정-확장2`(견적 ERD), `DESIGN.md`.
> **V1.1 (2026-11-02)**: 구현된 화면·경로·테이블(마이그레이션 0001~0028)로 갱신했다. 설계 당시 화면 번호(SCR-xx)는 바꾸지 않고, 폐지·통합·신규를 표시했다. PC 설치본(Track 7)에는 로그인과 승인함이 없다.

## 1. 사이트맵 (구현 기준)

```text
AX-CAD
├── 로그인 (/login)                              ── 서버 모드만 (PC 모드는 로그인 없음)
├── 홈 (/)                                        ── 내 프로젝트 카드(최근 생성순)
├── 프로젝트 (/projects)
│   └── 프로젝트 상세 (/projects/[projectId])     ── 도면 목록·새 도면(업로드 / 빈 도면 / 3D 모델부터)
├── 캐드 메뉴 (/cad)                              ── 프로젝트 없이 새 도면 작성·DXF/DWG 열기 (홈에도 표시)
├── 도면 상세·개정 이력 (/documents/[documentId]) ── 리비전 목록, 견적 목록("3D 모델로 견적"), BOM 링크
│   ├── 워크벤치: 2D Draft (/viewer/[revisionId]) ── 뷰어·작도·편집·측정·PDF 출력·견적 메트릭·공사 견적
│   ├── 워크벤치: 3D Model (/model/[documentId]) ── 스케치·Feature 트리·직접 선택·측정·"도면 만들기"
│   └── BOM (/documents/[documentId]/bom)         ── CSV/JSON, "ERP 업로드 파일(Excel)"
├── 견적 빌더 (/quotes/[quoteId])                  ── 워크벤치: Quote (라인·요약·시나리오·검증·추적·견적서 출력)
└── 관리 (/admin)
    ├── 기준정보 (/admin/master-data)              ── G1 가져오기·버전·재질·공정·단가·공종·품셈·보정
    ├── 사용자 (/admin/users)                      ── 서버 모드만
    ├── 감사 로그 (/admin/audit)
    └── 업데이트 (/admin/updates)                  ── PC 설치본 관리자: R 표기·변경 내역·패치 적용·결과
```

> 💡 FreeCAD처럼 **워크벤치(작업 모드)**를 상단 탭으로 전환한다: `Draft | Model | Quote`. 같은 도면 컨텍스트를 유지한 채 모드만 바뀐다(`DESIGN.md` §1).
>
> **주 메뉴**(`AppShell`): 홈 · 프로젝트 · 사용자(서버 모드 ADMIN) · 기준정보(ESTIMATOR 이상) · 감사 로그(REVIEWER 이상) · 업데이트(PC 모드 ADMIN). 설계 당시의 `승인함`, `연동 작업 모니터링`, 견적 목록·견적서 미리보기 별도 화면은 없다.

## 3. 화면 간 이동 경로 (Navigation Flow)

```text
[홈 SCR-02] → [프로젝트 목록 SCR-03] → [프로젝트 상세 SCR-04] ─┬→ [도면 상세 SCR-05] ─┬→ [2D Draft SCR-06] ⇄ [3D Model SCR-07]   (워크벤치 탭)
                                                              │                      ├→ "견적" 영역 → [견적 빌더 SCR-09]
                                                              │                      └→ [BOM SCR-14] → ERP 업로드 파일(Excel) 내려받기
                                                              └→ (새 도면: 업로드 / 빈 도면 / 3D 모델부터)
[SCR-06] 견적 메트릭 · 공사 견적 → [견적 빌더 SCR-09] ─┬→ [추적 드로어 SCR-10] → (원천 도면 하이라이트 SCR-06/07)
[SCR-07] 도면 만들기 → 새 도면 리비전(DXF) → [SCR-06]  └→ 견적서 PDF·Excel 출력
[관리 메뉴] 기준정보 SCR-16 · 감사 로그 SCR-18 · 업데이트 SCR-19 (· 사용자 SCR-15는 서버 모드)
```

- 워크벤치 3종(SCR-06/07/09)은 동일 레이아웃 쉘을 공유하며 상단 탭으로 전환한다.
- SCR-10에서 "도면에서 보기"를 누르면 SCR-06(또는 07)을 열고 해당 `entity_handle`/Feature를 선택 상태로 만든다.
- 설계 당시의 승인 경로(도면 상세 → 승인 요청 → 승인함)와 ERP 전송 경로(BOM → 연동 작업)는 제거되었다.
