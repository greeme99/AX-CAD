# AX-CAD 테스트 계획 및 결과 보고서 V1.26

> 7단계 개발 절차 중 **7단계 산출물**.
> 현재(2026-10-09)는 개발 착수 전이므로 **테스트 케이스·기준을 확정한 계획서**이며, 결과 열은 각 스프린트 Review 시점에 채운다. 실행하지 않은 테스트는 "미수행"으로 표기한다.

## 1. 테스트 개요

| 항목 | 내용 |
|---|---|
| 테스트 기간 | 스프린트마다 상시(CI) + 릴리스 리뷰 시점(R1 2027-01-15, R2 02-26, R3 04-23, R4 05-07 UAT) |
| 테스트 환경 | macOS/Linux 개발 PC, Docker(Postgres 16), Chrome·Edge 최신, 해상도 1440×900 / 1280×800 / 1024×768(태블릿 조회) |
| 테스트 데이터 | `tests/fixtures/` 익명화 샘플 DXF ≥15, STEP ≥5, 악성 샘플 세트, 기대값 YAML |
| 테스트 범위 | FN-01 ~ FN-26 (기능명세서) + NFR-01~09 |

### 1.1 테스트 레벨

| 레벨 | 도구 | 대상 | 실행 시점 |
|---|---|---|---|
| 단위 | pytest, Vitest | `core/*`, `frontend/lib/cad/*` | 커밋·CI |
| 통합 | pytest + FastAPI TestClient + 테스트 DB | API·트리거·서비스 | CI |
| 회귀 | pytest (fixtures + expected YAML) | 샘플 도면 메트릭·견적 | CI |
| 컴포넌트 | Vitest + Testing Library | 패널·테이블·상태머신 UI | CI |
| E2E | Playwright | 업로드→작도→저장, 견적 산출→추적→출력 | 스프린트 종료 |
| 성능 | pytest-benchmark / 브라우저 성능 측정 | NFR-01, 02 | S1, S3, S7 |
| 보안 | pytest(악성 파일), `security-reviewer` | 업로드·인증·권한 | S1, S4, S12 |
| 인수(UAT) | 실사용자 시나리오 | 릴리스 단위 | R1~R4 리뷰 |
