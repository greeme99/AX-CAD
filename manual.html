01 · SkCAD 한눈에 보기

SkCAD는 2D 제도·팀 공유·AI·3D를 브라우저 하나에서 처리합니다

2D CAD + KS 제도

AutoCAD 방식 그대로

  • 명령창·별칭(L, C, TR…), 객체스냅, 직교
  • 치수 5종, 지시선
  • 표면 거칠기, 기하 공차, 데이텀, KS 도면 양식(표제란·투상법)
  • DXF · PDF · PNG 출력

팀 보관함

한 사람이 고치고, 모두가 봅니다

  • 서버 PC 한 대에 도면을 모아 둡니다
  • 편집 중인 도면은 다른 사람에게 읽기 전용
  • 2초마다 자동 저장, 이전 판 20개 보관

AI · 3D

말로 그리고, 입체로 확인

  • Claude가 MCP로 화면에 직접 작도
  • [3D] 버튼으로 형상을 SolidCraft 창에 보내 두께만큼 돌출

혼자 쓸 때는 SkCAD 폴더의 index.html 을 더블클릭해도 됩니다. 이때는 팀·AI·3D 기능이 없습니다.

02 · 서버 PC 설치

서버 PC에는 Node.js와 SkCAD 폴더만 있으면 시작할 수 있습니다

구성 요소필요한 PC용도설치 · 확인
Node.js 22 이상서버 PCSkCAD 서버 · MCP 실행nodejs.org 에서 LTS 설치 → 명령창 node -v
SkCAD 폴더서버 PC화면 · 서버 · 실행기받은 폴더를 원하는 위치에 복사 (git 사용 시 저장소 복제)
SolidCraft 웹판 0.29.0서버 PC3D 내보내기 창server\get-solidcraft.ps1 — 약 35MB 를 받아 SHA-256 검증 후 설치

Claude 데스크톱 / CodeAI 쓰는 PC말로 작도 (MCP)선택 사항 — 14쪽 등록 방법

SolidCraft 는 MIT OR Apache-2.0 오픈소스입니다(vendor\solidcraft-web 의 LICENSE · NOTICE). 웹판은 git 에 들어 있지 않아 PC 마다 한 번 받습니다.

02 · 서버 PC 설치

설치는 다섯 단계이고, 그다음부터는 start.bat만 실행합니다

01

폴더 복사

SkCAD 폴더를 서버 PC 에 둡니다.

02

Node.js 설치

22 이상. 명령창에서 node -v 로 확인합니다.

03

3D 구성 요소

SkCAD 폴더에서 PowerShell:
powershell -ExecutionPolicy Bypass -File server\get-solidcraft.ps1

04

설정

.env.example 을 .env 로 복사합니다. 포트(SKCAD_PORT)와 주소(SKCAD_HOST)를 정합니다. 기본값이면 생략해도 됩니다.

05

실행

start.bat 더블클릭 → 서버가 뜨면 브라우저가 자동으로 열립니다. 창은 켜 둡니다.

끄기: stop.bat. 창을 그냥 닫아 서버가 남아도 다음 start.bat 이 자동으로 정리합니다. 다른 프로그램이 포트를 쓰면 [ERROR] 를 내고 멈춥니다.

02 · 서버 PC 설치

팀원이 쓰려면 사내망 공개, 방화벽 허용, 토큰 전달이 필요합니다

이 PC만 (기본)

혼자 쓰거나 AI 작업만 할 때

SKCAD_HOST=127.0.0.1
  • 다른 PC 에서는 접속할 수 없습니다
  • 방화벽 설정이 필요 없습니다
  • 주소: http://127.0.0.1:8770

사내망 공개

팀원이 접속할 때 — 관리자가 직접 설정

SKCAD_HOST=0.0.0.0        (.env 수정 후 start.bat 다시 실행)
  • Windows 방화벽 인바운드 허용 (관리자 PowerShell):
New-NetFirewallRule -DisplayName "SkCAD 8770" -Direction Inbound -Protocol TCP -LocalPort 8770 -Action Allow -Profile Domain,Private
  • 팀 토큰: data\team-token 내용을 메신저 등 별도 경로로 전달
  • 토큰 교체: stop.bat → team-token 삭제 → start.bat (새로 생성)

토큰을 주소(URL)나 공용 게시판에 올리지 마세요. 토큰이 있으면 보관함의 모든 도면을 읽고 쓸 수 있습니다.

상단 오른쪽 표시가 지금 상태입니다: «편집 중 · rev N» / «읽기 전용 — ○○ 편집 중» / «연결 끊김 — 다시 연결 중».

03 · 팀원 접속과 공동 작업

한 도면은 한 사람만 고치고, 나머지는 실시간으로 봅니다

상태상단 표시동작
편집 중편집 중 · rev N2초마다 자동 저장, 30초마다 잠금 연장. 저장(Ctrl+S)도 보관함에 저장합니다.
읽기 전용읽기 전용 — ○○ 편집 중고쳐도 바로 취소됩니다. 편집자가 저장하면 화면이 자동으로 새 판으로 바뀝니다.
잠금 풀림(자동 전환)편집자가 탭을 닫거나 «잠금 풀고 닫기»를 누르면, 보고 있던 사람이 최신 판으로 편집권을 받습니다.
저장 충돌저장 충돌 — 새 도면으로 저장내 화면 내용은 그대로 남습니다. [팀] → «새 도면으로 저장»으로 따로 보관하세요.
연결 끊김연결 끊김 — 다시 연결 중자동으로 다시 접속하고 잠금도 다시 얻습니다.
이전 판—서버의 data\history 에 도면마다 최근 20개가 남습니다. 복구는 관리자에게 요청합니다.

04 · 도면 작업 기본

도면은 SkCAD 파일, DXF, PDF, PNG로 저장하고 내보냅니다

저장 · DXF

원본은 .skcad

  • 저장 Ctrl+S → .skcad (팀 도면이면 보관함)
  • DXF 전체: 치수·기호는 선·문자로 풀어서 저장
  • DXF 형상만: 선·원·호·폴리선만 (다른 3D 프로그램용)

PDF 출력

Ctrl+P

  • 도면 양식이 있으면 1:1, 없으면 용지에 맞춤
  • 용지 A2 · A3 · A4, 흑백 선택
  • 인쇄 창에서 대상 «PDF로 저장»

PNG · 열기

그림과 가져오기

  • PNG: 도면 전체를 그림으로
  • 열기 Ctrl+O: .skcad, .dxf (AutoCAD 2000 이후, 블록·MTEXT 포함)
  • 못 읽은 객체 종류는 명령창에 건수로 알려 줍니다

브라우저를 닫아도 마지막 작업은 그 브라우저에 자동 보관되어 다음에 열 때 복원됩니다.

다른 사람 화면을 내 Claude 가 조작하지 못하게 막은 보안 설계입니다. 팀원이 AI 로 작도하려면 자기 PC 에 SkCAD 를 설치하고 start.bat 을 실행해 쓰세요. 이때 보관함은 그 PC 에 따로 생기므로, 완성한 도면은 팀 서버 화면에서 «새 도면으로 저장»으로 올립니다.

06 · AI(MCP) 연동

Claude 데스크톱은 설정 파일에, Claude Code는 명령 한 줄로 등록합니다

Claude 데스크톱

%APPDATA%\Claude\claude_desktop_config.json 의 "mcpServers" 안에 추가

"skcad": {
  "command": "C:\\Program Files\\nodejs\\node.exe",
  "args": ["<SkCAD 폴더>\\server\\mcp.js"]
}
  • 경로의 \ 는 \\ 로 두 번 씁니다
  • 저장 후 Claude 를 트레이까지 완전히 끄고 다시 실행합니다

Claude Code

터미널에서 한 번 실행

claude mcp add --scope user skcad -- node "<SkCAD 폴더>\server\mcp.js"
  • 새 세션을 열어야 도구가 보입니다
  • /mcp 에서 skcad 가 connected 인지 확인합니다

팀 토큰과 포트는 mcp.js 가 data\team-token 과 .env 에서 스스로 읽습니다. 설정 파일에 토큰을 적지 마세요.

06 · AI(MCP) 연동

서버를 켜고 AI 연결을 허용한 뒤, Claude에게 말로 요청합니다

  1. start.bat 실행 → 열린 http://127.0.0.1:8770 화면
  2. [팀] → «AI(MCP) 연결 허용» 체크 → 상단에 «AI 연결» 표시
  3. Claude 에게 요청합니다. 예:
    • 100×60 판을 그리고 좌우 25mm 위치에 지름 20 구멍 두 개
    • 가로·세로 치수와 윗면에 표면 거칠기 y
    • KS A3 양식, 작품명 «브래킷»
    • 지금 그림 보여 줘 · 보관함에 «브래킷 v1»로 저장해 줘

Claude 는 상태 확인 → 명령 실행 → 그림 확인 순서로 작업하고, 그리는 과정이 화면에 그대로 보입니다.

AI 는 새 도면 · 파일 열기 · 파일 저장 · DXF/PNG · 인쇄 · 도움말 명령을 쓸 수 없습니다(대화상자·다운로드 방지). 사용자가 명령을 하던 중이면 Esc 로 끝낸 뒤 요청하세요.

06 · AI(MCP) 연동

Claude가 쓰는 SkCAD 도구는 일곱 가지입니다

도구하는 일
skcad_status서버 연결, AI 허용 화면, 열린 도면 확인
skcad_run명령창 입력을 차례로 실행 — 그리기 · 수정 · 치수 · KS 기호 · 3D
skcad_get_drawing도면층과 객체 목록(id · 좌표)
skcad_snapshot도면 전체를 PNG 그림으로 받아 결과 확인
skcad_list_drawings팀 보관함 목록(편집 중인 사람 포함)
skcad_open_drawing보관함 도면 열기 — 편집 잠금을 시도
skcad_save보관함에 저장 — 보관함 도면이면 새 판, 아니면 새로 만듦

객체를 고르는 단계에서는 #id 또는 #id@x,y(자르기·연장 위치), 선택 단계에서는 #3,#5 · ALL · LAST 를 씁니다. Claude 가 알아서 사용합니다.
