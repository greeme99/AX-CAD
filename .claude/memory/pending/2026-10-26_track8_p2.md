# 반영 대기: Track 8 P2 3D 모델링 코어 (2026-10-26)

반영 위치 제안: `MEMORY.md`의 아키텍처 결정·함정 절.

- (ADR) 3D 모서리·면 참조는 번호가 아닌 기하 특징(종류·중간점·방향·길이/넓이·반지름, `core/geometry/refs.py`)으로 저장한다. 재생성 때 같은 종류·방향·반지름 중 몸체 크기 10% 안의 가장 가까운 것을 쓰고, 없으면 `GEOM_REF_LOST`.
- (ADR) 스케치 윤곽 규칙은 FreeCAD와 같다: 포함 관계로 겹쳐 홀수 깊이는 구멍, 나머지는 외곽(섬 포함), 떨어진 외곽 여러 개도 한 번에 돌출·포켓. DXF 프로파일(스케치 아님)은 닫힌 윤곽 하나만.
- (ADR) 억제한 가공·Boolean·Pocket은 기준 몸체(`target_feature_id`)를 그대로 넘긴다. 억제 여부는 BREP 캐시 키에 들어간다.
- (ADR) 롤백 위치 삽입(`insert_after`): 새 피처가 뒤 피처가 쓰던 몸체를 받으면 뒤 피처의 `target_feature_id`/`tool_feature_id`를 새 피처로 바꿔 재생성한다. seq는 두 단계 UPDATE(음수 → 양수)로 민다(유일 제약).
- (규격) 구멍 마법사 표는 `core/geometry/holes_std.py`: KS B 0201/ISO 262 탭 드릴 = D − P, KS B 1007/ISO 273 3등급, 카운터보어·접시는 업계 참고값(사내 기준 오면 표만 교체).
- (검증 도구) `uv run python -m tests.freecad_examples <.fcstd...>`: FreeCAD 없이 FCStd를 읽어 Pad/Pocket/Revolution을 AX-CAD 커널로 재구성해 부피 비교. 예제 파일은 저장소 밖(`/home/user/freecad-org/Examples`), 라이선스 표기가 없어 숫자만 기록.
- (함정) OCP에 `OCP.GCPnt` 없음 → 길이는 `BRepGProp.LinearProperties_s`. 저장소에 prettier 설정 없음 → 기존 파일에 prettier 금지.
