# ADR-12 (초안, 승인 대기) — Track 8 표준 CAD 완결 방식

- 결정(2026-10-25 사용자, grill-me): **D′ 하이브리드**. OCCT 직접 호출(HLR·로프트·스윕·구배·두께·면까지 돌출·최소거리·형상검사) + FreeCAD 고유 로직만 클린룸 재구현(LGPL-2.1, 코드 복사 금지). 스케치 솔버는 numpy로 구현하고 새 의존성은 두지 않는다.
- REA(morluto/rea)는 쓰지 않는다: 소스가 공개된 저장소 분석은 REA 자체 지침상 대상 외. FreeCAD는 개발용 검증 오라클로만 쓰고 배포하지 않는다.
- 참조 소스: 원본 `freecad/freecad`를 기준으로 하고 포크 `greeme99/FreeCAD`를 함께 본다(클라우드 shallow clone, 분석 노트에 참조 커밋 기록).
- 순서: P1 2D 완성(+ P5 준비) → P2 3D 코어 → P3 도면화 → P4 견적 연계 → P5 마무리(R1.0 릴리스·리허설).
- DWG: ODA File Converter를 사용자가 설치한 PC에서만 선택 연동한다. 설치본에는 포함하지 않는다.
- 검증: 저장소 합성 샘플로 자동 검증하고, 실도면은 사용자 PC UAT 체크리스트로 확인한 뒤 숫자만 공유한다.
- 릴리스: P1~P5 완료 설치본 = R1.0 기준선, 이후 업데이트(R1.1)·업그레이드(R2.0) 등급별 패치 확장(기능은 R1.0에 포함).
