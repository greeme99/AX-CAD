- **ADR-07 (견적 불변성, 2026-10-10)**: 금액·원천·계보는 앱이 아니라 **DB 트리거**로 고정한다.
  - 견적 헤더 가드(0013): 불변 컬럼 + 허용 상태 전이만(DRAFT↔IN_REVIEW→CONFIRMED→SUPERSEDED, DRAFT→ABANDONED).
  - 확정 견적은 Revision(COPY/RECALC, `<root>-R<n>`, 폐기 번호 미재사용)으로만 바뀌고, 승인자는 체인 전체 작성자·조정자가 아니어야 함.
  - 정식 견적서는 최초 발행본 bytes를 저장해 재발행 시 동일 파일. 내부 산출근거는 초안 전용.
  - 증거 테이블이 있으면 downgrade 거부, 머지된 마이그레이션은 새 리비전으로만 변경.
- **ADR-08 (ERP 연동, 2026-10-10)**:
  - 멱등 키 `BOM:{doc}:{revision|MODEL:hash16}`, 백그라운드 전송 + `run_id` 펜싱, 최대 3회(5xx/408/425/429만 재시도), 리다이렉트 불허.
  - https만(개발 localhost http 예외). 토큰은 환경변수에서만 읽고 저장·응답 노출 금지, ERP 응답 본문은 ADMIN만 열람.
  - `request_payload`는 불변이며 감사 로그엔 INSERT 때 1회만 남음(0014).
- **운영 규칙 (Track 2)**: PR은 GitHub Actions CI 녹색 후 머지. 요청 검증 오류는 422 `REQUEST_INVALID` + `details[{field,type}]`(입력값 미반사). 감사 로그는 REVIEWER에게 구성원 프로젝트 범위만.

※ MEMORY.md가 이미 프로젝트 메모리 한도(약 2,000자)를 넘음(현재 약 5,100자). 반영 시 §2(견적 공식, `.claude/rules/quote-engine.md`와 중복)·§3(초기 ERD 명칭, 실제 스키마와 다름)·§4(규칙 파일과 중복)를 규칙 파일 참조 한 줄로 압축하는 것을 함께 제안한다.
