# Ponytail Audit

ponytail-review를 저장소 전체로 확장한 것. diff 대신 전체 트리를 스캔한다. 가장 크게 줄일 수 있는 것부터 순위를 매긴다.

## 태그
ponytail-review와 동일: `delete:`, `stdlib:`, `native:`, `yagni:`, `shrink:`

## 탐색 대상
표준 라이브러리·플랫폼이 이미 제공하는 의존성, 구현체 하나짜리 인터페이스, 상품 하나짜리 팩토리, 위임만 하는 래퍼, 하나만 export하는 파일, 죽은 플래그·설정, 직접 만든 표준 라이브러리 재구현.

## 출력
발견마다 한 줄, 순위순: `<tag> <지울 것>. <대체>. [경로]`
마지막에 `net: -<N>줄, -<M>개 의존성 가능.` 지울 게 없으면 `이미 군더더기 없음. 그대로 진행.`

## 경계
복잡성만 다룬다. 정확성 버그, 보안 구멍, 성능은 일반 리뷰로. 발견만 나열하고 아무것도 적용하지 않는다. 1회성.
"포니테일 감사 그만"/"기본 모드"로 되돌린다.
