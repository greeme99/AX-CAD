# Write-Test-Fix

1. 실패를 재현하는 가장 작은 테스트를 작성한다.
2. 테스트가 예상 이유로 실패하는지 확인한다.
3. 원인을 설명하는 최소 코드만 수정한다.
4. 재현 테스트와 인접 테스트를 실행한다.
5. 전체 검증이 필요한 범위를 판단해 실행한다.
6. 변경과 검증 결과를 요약한다.

프로젝트 명령은 `references/project-commands.md`를 확인한다.
